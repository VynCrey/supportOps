## Qué falló, en cadena

1. **Triage → `general`.** El prompt solo traía una regla para `api` y ninguna descripción de las demás categorías.
2. **Conocimiento → `grafo`.** Con categoría `general`, el grafo no tiene documentos y la búsqueda siempre vuelve vacía. Con `lexical`, la consulta que escribió el modelo para T02 habría traído KB-046, el documento correcto.
3. **Borrador → citó el ID del ticket** ("20003", "20004"). El modelo recibía el `id` del ticket junto con el texto. Por eso el mismo T01 dio otro resultado en la máquina de Marco (ticket 7, ejecución 5: evidencia KB-056).
4. **Gate → `bloquear` por cita inexistente.** Es correcto. El supervisor del modelo había dicho `revisar`.

Además, el borrador pidió el "endpoint" en dos problemas de inicio de sesión porque el prompt lo daba como ejemplo de dato a pedir.
