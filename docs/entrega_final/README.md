# Informe final de SupportOps

- `SupportOps_Informe_Tecnico_2026.pdf`: informe técnico actualizado del sistema local de dos pantallas, catálogo ficticio, reclamos, IA supervisada, seguridad, pruebas e instalación. Paleta turquesa y gris, índice y portada conceptual.
- `generar_informe_tecnico.py`: fuente reproducible de ese PDF. Usa ReportLab y la imagen `portada_ia.png`.
- `SupportOps_Informe_Proyecto_Integrador_2026.pdf`: versión institucional anterior, conservada como antecedente del proyecto.
- `logo_instituto.png`: imagen de 270 × 80 px extraída de `SIPCTM_TIF.pptx`, facilitada para esta entrega. El PDF la dibuja con la misma medida y proporción en todas sus páginas.
- `portada_ia.png`: ilustración editorial en tonos pastel generada con inteligencia artificial para la carátula; no representa una captura del sistema.
- `generar_informe.py`: código fuente del PDF. Requiere Python con `reportlab` y `Pillow`; estas bibliotecas son solo para regenerar el informe, no para ejecutar SupportOps.

El contenido se contrastó con la plantilla institucional, el código y las evidencias versionadas del repositorio. Los resultados H5 corresponden a la corrida del 27/10/2026 y no se presentan como una nueva medición del código actual.
